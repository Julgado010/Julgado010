## 🚀 Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas na UDF** e estou focado em uma das áreas que mais crescem no mercado: a **automação com Inteligência Artificial**.

Meu caminho é aprender bem a **base da programação** (lógica, estrutura de código e banco de dados) para saber **guiar a IA** com clareza. Eu mostro o caminho, defino o que precisa ser feito, e a IA me ajuda a construir sites, automações e outras soluções. Para isso funcionar, preciso entender o que está sendo gerado, revisar o código e corrigir o que for necessário.

Hoje estudo **JavaScript, Java e Banco de Dados**, e uso projetos práticos da faculdade para consolidar o aprendizado.

**Minhas metas:**
- 🎯 Conquistar um estágio ou primeira oportunidade na área de desenvolvimento e automação com IA
- 🤖 Aprender a criar automações e sistemas completos usando IA com qualidade, revisão e boas práticas
- 📚 Aprofundar meus fundamentos em JavaScript, Java e bancos de dados para ter autonomia técnica

### 💭 O que aprendi com esses perfis

Ao analisar os 10 perfis, percebi que os melhores não são os mais enfeitados, e sim os mais objetivos. Perfis como os de Addy Osmani e Nuno Coração se apresentam em poucas linhas: dizem o que fazem, em que projetos trabalham e como entrar em contato. Isso me mostrou que o Profile README deve funcionar como um cartão de visitas e não como um currículo longo. Outro padrão forte foi a curadoria dos repositórios fixados: cada profissional destaca poucos projetos, com nomes claros e descrições de uma linha, em vez de deixar trabalhos soltos e genéricos. Também notei que quase todos os projetos têm README organizado, com explicação do que o projeto faz, exemplos de uso e licença explícita, o que transmite profissionalismo e facilita a vida de quem quer usar o código. Como estudo automação com IA, isso é ainda mais importante para mim: documentar bem é o que mostra que eu entendo o que foi construído e sei guiar a IA. Percebi ainda que a consistência importa, pois issues, pull requests e releases públicos mostram trabalho contínuo e colaborativo. Por isso, adotei um README de perfil curto, com stack em badges e links para meus projetos, fixei repositórios com nomes descritivos, destaquei o projeto deste semestre e padronizei o README de cada projeto com visão geral, tecnologias, instruções de execução, prints, LICENSE e .gitignore.
